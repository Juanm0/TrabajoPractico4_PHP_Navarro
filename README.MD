Fecha de entrega
A asignar por su profesor.

Objetivos
1. Utilizar variables y operadores.
2. Aplicar estructuras condicionales.
3. Utilizar bucles.
4. Crear algoritmos simples.
5. Integrar PHP con HTML.

Forma de entrega
Entregar por classroom una carpeta NombreApellido.zip que contenga los archivos
desarrollados.

Conformación del grupo
El trabajo práctico es individual.

Consignas de evaluación
1. Saludo personalizado:
a. Crear un programa que almacene en una variable el nombre de una
persona y muestre el siguiente mensaje utilizando la instrucción echo:
“Hola Juan, bienvenido a PHP.”

2

2. Operaciones matemáticas:

Crear dos variables numéricas y mostrar:
a. Suma.
b. Resta.
c. Multiplicación.
d. División.
Ejemplo:
Suma: 15
Resta: 5
Multiplicación: 50
División: 2
3. Número par o impar:

Crear una variable que contenga un número entero y determinar si el
número es:
a. Par.
b. Impar.
c. Cero.
d. Mostrar un mensaje indicando el resultado.
Ejemplo:
“El número 8 es par.”

4. Mayor de edad:
a. Crear una variable llamada edad.
b. Utilizar una estructura if para indicar si una persona es:
c. Mayor de edad (18 o más)
d. Menor de edad
e. Mostrar un mensaje indicando el resultado.
Ejemplo:
“La persona es mayor de edad.”

3

5. Tabla de multiplicar:
a. Crear una variable con número.
b. Utilizar un bucle for para mostrar su tabla de multiplicar del 1 al 10.
Ejemplo:
5 x 1 = 5
5 x 2 = 10
...
5 x 10 = 50

6. Contador de números pares.

Utilizando un bucle for, mostrar todos los números pares comprendidos
entre 1 y 100.
Ejemplo:
2
4
6
8
...
100

7. Promedio de notas.
a. Crear tres variables que representan las notas de un alumno.
b. Calcular el promedio y mostrar:
i. El promedio obtenido.
ii. Si el alumno aprobó o desaprobó.
iii. Considerar aprobado con promedio mayor o igual a 7.
Ejemplo:
Promedio: 8
Estado: Aprobado

4

8. Página HTML generada con PHP.
a. Crear una página HTML que muestre:
i. Un título.
ii. Un párrafo.
b. Tanto el título como el párrafo deben generarse utilizando PHP.
9. Lista de alumnos utilizando HTML y PHP.
a. Crear un array con al menos cinco nombres de alumnos.
b. Utilizar un bucle foreach para generar una lista HTML.
c. Todo el contenido debe generarse mediante PHP.
10. Tabla HTML de productos.
a. Crear un arreglo que contenga información de tres productos.
b. Cada producto debe tener:
i. Nombre.
ii. Precio.
c. Generar una tabla HTML utilizando PHP.
Ejemplo:

Producto Precio
Mouse $15000
Teclado $25000
Monitor $180000

d. La tabla debe construirse dinámicamente utilizando un bucle.

5

11. Calculadora:

Crear una calculadora sencilla utilizando HTML y PHP, la página deberá
permitir:
a. Ingresar dos números.
b. Seleccionar una operación:
i. Suma.
ii. Resta.
iii. Multiplicación.
iv. División.
c. Mostrar el resultado.

Recomendaciones técnicas:
Crear la carpeta Raíz del proyecto /NombreApellido
Dentro de la carpeta raíz, crear una subcarpeta para cada ejercicio:
NombreApellido
│
├── Ejercicio1
├── Ejercicio2
├── Ejercicio3
├── ...
└── Ejercicio11
Nombrar los archivos de manera clara y descriptiva como ejercicio1.php, ejercicio2.php.
Mantener una correcta indentación del código para facilitar su lectura.
Agregar comentarios (// o /**/) cuando sea necesario para explicar partes
importantes del algoritmo.
Verificar que todos los ejercicios funcionen correctamente antes de realizar la entrega.
Evitar copiar y pegar código sin comprender su funcionamiento.
Probar diferentes valores para comprobar que el algoritmo funciona en distintos casos.
6

Se valorará especialmente la correcta organización del proyecto, la claridad del
código y la utilización de buenas prácticas de programación, además del correcto
